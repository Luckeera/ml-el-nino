Atividade 1 – Projeto de Machine Learning (Fase Inicial – CRISP-DM)



Objetivo

Nesta primeira entrega, os grupos (6 integrantes/equipe) deverão desenvolver as etapas iniciais do projeto seguindo a metodologia CRISP-DM, com foco em:

Entendimento do Negócio
Entendimento dos Dados

O objetivo é garantir uma compreensão clara do problema, do contexto e dos dados antes de avançar para modelagem.



Entregáveis

Os alunos deverão submeter:

Notebook (.ipynb) com análises e códigos executáveis


1. Entendimento do Negócio

Nesta etapa, o grupo deve estruturar o problema de forma clara e justificável.

O que deve ser apresentado:

Contextualização do problema
Descrição do cenário (domínio de aplicação)
Motivação prática ou científica
Relevância do problema
Definição do problema
Qual problema será resolvido?
Trata-se de:
Classificação?
Regressão?
Agrupamento?
Outro tipo?
Objetivo da solução
Qual a saída esperada do algoritmo?
Exemplo:
Classe prevista
Valor numérico
Segmentos de dados
Tipo de aprendizado
Machine Learning supervisionado ou não supervisionado?
Justificar a escolha com base no problema e nos dados
Critérios de sucesso (opcional, mas recomendado)
Impacto esperado da solução


2. Entendimento dos Dados

Nesta etapa, o grupo deve explorar e caracterizar a base de dados.

O que deve ser apresentado:

Fonte dos dados
Origem da base (Kaggle, UCI, dados próprios, APIs, etc.)
Link ou referência
Descrição geral da base
Número de instâncias (linhas)
Número de atributos (colunas)
Tipos de dados (numéricos, categóricos, texto, etc.)
Dicionário de dados
Breve descrição das principais variáveis
Análise Exploratória de Dados (EDA)
Estatísticas descritivas
Identificação de valores ausentes
Distribuição das variáveis
Correlações relevantes (quando aplicável)
Visualizações
Gráficos adequados ao tipo de dado:
Histogramas
Boxplots
Gráficos de barras
Heatmaps de correlação
Interpretação dos principais padrões encontrados


Observações Importantes

Não é necessário realizar modelagem (algoritmo de machine learning) nesta etapa
O foco deve ser na compreensão do problema e dos dados
Justificativas são obrigatórias (não apenas descrição)
O notebook deve ser reprodutível (código executável e organizado)


Critérios de Avaliação

Clareza na definição do problema
Coerência entre problema e abordagem escolhida
Qualidade da análise exploratória
Uso adequado de visualizações
Organização e reprodutibilidade do notebook
